# Plano de execução
1. Importação auditável e testes do GitReverse (verificar licença/dependências/segredos; configurar LLM local ou API com cautela).
2. Benchmark de jornadas públicas de portais acadêmicos (sem acesso automatizado a áreas autenticadas).
3. MVP independente: dashboard, disciplinas, notas, calendário, financeiro, atendimento com dados sintéticos.
4. Evolução: API backend própria, autenticação de demonstração, testes de acessibilidade WCAG, observabilidade e CI.
5. Antes de operação real: autorização institucional, DPA/LGPD, SSO oficial, RBAC, testes de carga e segurança, migração consentida.

## Escala hipotética
500 mil alunos é requisito potencial de dimensionamento, **não** capacidade comprovada do protótipo. Validar com testes de carga e metas SLO negociadas.
